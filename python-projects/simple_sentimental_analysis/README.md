# Sentiment Analysis Tool (2023–2024)

**Tech:** Python, Flask, NLTK

**Overview:**  
Developed a program to analyze text sentiment (positive/negative/neutral) from reviews or social media. Includes preprocessing, model training, and prediction.

**Key Features:**  
- Text preprocessing: tokenization, stopword removal, lemmatization  
- Model training and evaluation  
- Real-time prediction through Flask app
